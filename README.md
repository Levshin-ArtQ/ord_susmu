# Ординатура · ЮУГМУ

Офлайн-расписание ординаторов на учебный год 2026–2027. Статический PWA: без сервера, без аккаунтов.

## Что умеет

- Сегодня: дисциплина, практика и лекция, день цикла
- План на несколько месяцев, циклы года
- Своя группа и подсмотреть чужую
- Время, место, контакты преподавателя — только на устройстве
- Таблица **сама не подтягивается**. Обновление — только кнопка «Обновить из таблицы» или файл xlsx

## Деплой на Vercel через GitHub

Репозиторий: [Levshin-ArtQ/ord_susmu](https://github.com/Levshin-ArtQ/ord_susmu). Это **статика** (HTML/JS), не Next.js.

1. [vercel.com/new](https://vercel.com/new)
2. Import **`Levshin-ArtQ/ord_susmu`** (если репозитория нет в списке: Configure GitHub App → разрешите этот repo)
3. **Framework Preset: Other**
4. **Root Directory:** не меняйте (файлы лежат в корне репозитория)
5. Build / Output не трогайте: `vercel.json` копирует сайт в `public/` на сборке
6. Deploy

После деплоя: открыть `https://….vercel.app` в Safari → Поделиться → На экран «Домой».

Локально:

```bash
npm run dev
```

## Данные

Первый запуск копирует встроенное расписание в IndexedDB. Новая версия сайта это **не затирает**. Чтобы взять свежую таблицу, в приложении: **Ещё → Обновить из таблицы**.

Пересобрать встроенную копию из xlsx:

```bash
python3 scripts/parse_schedule.py data/schedule.xlsx data
```
